# vcut 工作台（P1·工程版）

浏览器里的时间线，背后是同一份 EDL 和同一个渲染器。**没有假状态**：
你在界面上改一个拍数，渲出来的片子就真的变了。

## 启动

```bash
cd edit-core
python3 workbench/server.py 8799
# 打开 http://127.0.0.1:8799
```

零依赖（Python 标准库 + 已装好的 ffmpeg）。服务只监听 127.0.0.1。

## 界面

| 区域 | 能干什么 |
|---|---|
| 左·镜头 | 5 个镜头带缩略图、入点、拍数；蓝点 = 已换人 |
| 左·版本 | v1 / v2 …，点一下切换预览 |
| 中·时间线 | 拍点网格 + clip 块，点选镜头；红线跟随播放 |
| 中·播放器 | 直接播当前版本，支持拖动（HTTP Range） |
| 右·决策 | 选中镜头的拍数/源起点编辑 + 所有 op 的证据 |

## 一条完整操作

1. 点某个镜头（左栏或时间线）
2. 右栏改「拍数 8 → 12」或「源起点」，点**应用**
3. 中栏时间线立刻重排（切点仍吸附在拍上，字幕轴跟着重算）
4. 点右上**渲染新版本**，约 10 秒后出现 v2
5. 左栏点 v1 / v2 来回对比

## 接口（供后续接入）

```
GET  /api/state            项目 + EDL + 版本 + 任务状态
GET  /api/thumb?i=N        第 N 个镜头的缩略图（带缓存）
GET  /api/poster           当前版本的海报帧
POST /api/clip             {index, beats?, start?} → 重排并保存 EDL
POST /api/render           {label?} → 后台渲染，进度用 /api/state 轮询
GET  /media/vN.mp4         成片（支持 Range）
```
